## Design Context

### Users

Indonesian undergraduate students writing their **skripsi** (thesis) — and the lecturers / advisors who review those drafts. They span every discipline: engineering, biomedicine, law, humanities, education. They open CiteTrack at a desk, often during a high-stress revision pass days before a submission deadline. The job is concrete and self-defending: "find the language and citation problems my advisor will flag, before they do."

Many users are not technical and are not fluent in English. UI labels can be English, but user-facing prose, prompts, and explanations should sound like a thoughtful Indonesian editor — not a Silicon Valley product. The locale of the work product is Bahasa Indonesia; the locale of the *feelings* is academic Indonesia.

### Brand Personality

Three words, in priority order: **Trustworthy. Calm. Friendly.**

- **Trustworthy** comes first because students will defend the report to their advisor. The interface must read as carefully considered, never speculative or AI-handwavy. No confidence theater (no fake percentages, no "AI suggests…"). When the tool is uncertain, it says so plainly.
- **Calm** because thesis-writing is already stressful. The tool should feel like a still room. Generous whitespace, no urgency theatre, no streaks/badges/celebrations.
- **Friendly** in the Indonesian sense: warm, helpful, addresses the user with respect ("Tahukah kamu?", not "Pro tip!"). Conversational without being playful.

The interface should evoke the feeling of a senior research librarian sliding a marked-up draft back across the table.

### Aesthetic Direction

**Editorial / scholarly.** This is the canonical direction — commit to it fully.

- Asymmetric, magazine-style composition. Left-aligned headlines, hanging metadata, deliberate use of empty space. Break the grid for emphasis.
- A distinctive serif display face for headings (e.g. *Fraunces*, *Newsreader*, *Source Serif 4*) paired with a refined humanist sans for body and UI (e.g. *Geist*, *Inter Tight*, *IBM Plex Sans*). Avoid the AI defaults (plain Inter, Roboto, system).
- Findings are styled as **scholarly marginalia**, not dashboard cells. Hairline rules, small-caps page metadata, a vertical accent rule that hints at a margin annotation.
- Color is **restrained**. The palette already exists (`--sea-ink`, `--lagoon`, `--palm`, `--sand`, `--foam`, `--secondary`, `--accent`, `--destructive`); the editorial direction means using a *lot* of `--foam`/`--sand` and just enough `--sea-ink` and `--lagoon-deep` for ink. Severity color is a small badge, not a big block.
- Density is medium-to-high: this is a working document, not a marketing landing page. Spacing scales should breathe at the macro level (page padding, section separation) but stay compact inside finding rows.

**Theme**: Light-only. Don't ship a dark-mode that compromises the editorial feel.

#### Anti-references — explicitly NOT

- **AI / dashboard tropes**: purple→blue gradients, glowing dark UI, hero-metric layouts with sparklines, dense icon-prefixed identical-card grids.
- **Corporate SaaS**: generic blue-on-white, stock illustrations, every action a filled primary button, "Get Started" CTA energy.
- **Childish / gamified**: neon accents, gamification badges, confetti, mascot energy. This is a serious academic tool.

(Print-only / Word-doc look is fine as a *reference* — this is a scholarly tool — but the actual product is on screen and must behave like a modern web app, not Microsoft Word.)

### Design Principles

1. **Editorial composition over dashboard grids.** Compose pages like a journal article, not an analytics dashboard. Headlines as headlines, metadata as metadata, hanging columns, asymmetric layouts. Do not wrap everything in a card; do not repeat the same card grid endlessly.

2. **Calm authority.** Every detail reads as considered. Restrained color, intentional spacing, no urgency theatre. Severity is communicated through small, sharp badges and well-chosen ink tones — not large red/yellow fills that scream at the reader.

3. **The document is the subject.** The PDF preview is the heart of the page; findings are *annotations* on the document, not the document itself. Visual hierarchy, color weight, and layout asymmetry should reinforce that the user is looking at *their thesis with notes*, not a CRUD table.

4. **Ocean-tinted neutrals; pull every gray toward `--sea-ink`.** No pure black, no neutral gray. Borders are `color-mix(in oklab, var(--sea-ink) 10%, var(--foam))` energy. `--secondary` (soft yellow) and `--accent` (mint) are *accents*, not surfaces.

5. **Indonesian voice in the warm seams.** UI labels are English ("Evaluation Report", "Severity"), but the moments that talk *to* the user — tips, empty states, encouragements, error explanations — are warm, local, and respectful. Use "kamu" (informal-you) not "anda" (formal-you), and never write copy that sounds like it came from a corporate template.
